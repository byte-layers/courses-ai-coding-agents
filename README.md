# courses-ai-coding-agents

Les contenus du stack `ai-coding-agents` de byte_layers : coder avec un agent d'IA (modèles, harness,
configuration, garde-fous, développement piloté par les spécifications). Un dossier par contenu, à plat.

Le parcours du stack est décrit dans `stacks/ai-coding-agents/stack.yml`. Les fichiers de l'apprenant vont
dans `~/byte-layers/ai/`, et chaque contenu ne touche qu'à son propre sous-dossier.

Tous les labs de ce dépôt s'exécutent sur le poste de l'apprenant : l'agent et le modèle local y tournent.
